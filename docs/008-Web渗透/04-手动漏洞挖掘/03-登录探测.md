# 登录探测

## 0x01 用户名密码爆破
### 确定用户
> 先确定用户账号格式,一般为手机号或邮箱号或用户名或者有默认用户.可以去网站及子网站观察是否有相关信息,比如屏蔽4位的手机号,信息发布者用户名,联系邮箱等等信息.应该吧暴力返回控制在一个可接受范围.

### 确定密码  
> 可以尝试默认密码及常用弱密码和根据信息收集生成的定制密码.
