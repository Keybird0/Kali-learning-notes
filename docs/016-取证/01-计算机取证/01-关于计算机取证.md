# 取证科学
> 为侦破案件还原事实真相, 收集法庭证据的一系列科学方法.

### 注意点
+ 参考本地区法律要求
+ 遵守实践操作通用原则


## 0x01 通用原则
+ 维护证据完整性
  - 拷贝原始文件进行分析
  - 计算HASH验证数据完整性
+ 维护监管链
  + 数字证物原始版本写保护,使用拷贝进行分析
+ 标准的操作步骤
  + 证物使用严格按照按照规范流程,即使事后证明流程有误也可以免责
+ 取证分析过程全部作记录文档


### 数字取证者的座右铭
-	不要破坏数据现场（实际几乎无法实现）
-	寄存器、CPU缓存、I/O设备缓存等易失性数据几乎无法获取
-	系统内存是主要的非易失性存储介质取证对象,不修改无法获取其中数据
-	非易失性存储介质通常使用完整镜像拷贝保存
-	正常关机还是直接拔掉电源（数据丢失破坏, 建议还是直接拔电源）


### 安全痕迹
> 作为安全测试人员, 应在测试过程留下痕迹, 保证自己是合法的测试, 而非黑客攻击行为.
+ 通过取证还原黑客入侵的轨迹
+ 作为渗透测试和和黑客攻击区分标准
  + 举例: 世纪佳缘事件, 印象笔记渗透测试事件

## 0x02 计算机取证方法
+ 活取证
  -	抓取文件metadata、创建时间线、命令历史、分析日志文件、哈希摘要、转存内存信息
  -	使用未受感染的干净程序执行取证
  -	U盘 / 网络 存储收集到的数据
  - 主要取证内容为内存数据
+ 死取证
  -	关机后制作硬盘镜像、分析镜像（MBR、GPT、LVM）
