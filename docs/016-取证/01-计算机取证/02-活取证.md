## 0x02 分析内存

### volatility

```bash
# 显示帮组
volatility -h

# 分析文件信息, 应注意Suggested Profile(s)
volatility -f xp.raw imageinfo

# 显示运行程序
volatility -f xp.raw --profile=WinXPSP3x86  pstree

# 查看注册表信息列表
volatility -f xp.raw --profile=WinXPSP3x86  hivelist
# 查看注册表信息
volatility -f xp.raw --profile=WinXPSP3x86  hivedump -o 0xe14b9758 (这是Virtual地址)
# 按虚内存地址查看注册表内容, 查看用户
volatility -f xp.raw --profile=WinXPSP3x86  printkey -K "SAM\Domains \Account\Users\Names"

# 最后登录的用户
volatility -f xp.raw --profile=WinXPSP3x86  printkey  -K "SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" 

# 正在运行的程序、运行过多少次、最后—次运行时间等
volatility -f xp.raw --profile=WinXPSP3x86  userassist

# dump特定进程
volatility -f xp.raw --profile=WinXPSP3x86 memdump -p < pid > -D test

# cd ./test
strings 324.dmp > string.txt # 可以分析一些明文信息 可以grep

# 其它
volatility -f xp.raw --profile=WinXPSP3x86 cmdscan
volatility -f xp.raw --profile=WinXPSP3x86 netscan

# dump NTLM
volatility -f xp.raw --profile=WinXPSP3x86 hivelist
volatility -f xp.raw --profile=WinXPSP3x86 hashdump -y <system 地址> -s  <sam地址>

# 活动分析
volatility -f xp.raw --profile=WinXPSP3x86 timeliner

#  其它插件安装(把下载的py文件拷贝到/usr/lib/python2.7/dist-packages/volatility/plugins/
)
https://github.com/sans-dfir/sift-files/tree/master/volatility

# Firefox History 等
https://downloads.volatilityfoundation.org/contest/2014/DaveLasalle_ForensicSuite.zip

# USN日志记录解析
https://raw.githubusercontent.com/tomspencer/volatility/master/usnparser/usnparser.py
–	volatility -f wp.raw --profile=WinXPSP3x86 usnparser --output=csv --output-file=usn.csv

# 内存取证发现恶意软件
https://github.com/volatilityfoundation/volatility/wiki/Memory-Samples


volatility -f xp.raw profile=WinXPSP3x86 pstree
volatility connscan	# 网络连接
volatility getsids -p 111,222 # SID
volatility dlllist -p 111,222	# 数星
volatility malfind -p 111,222 -D test	# 检查杀毒结果查毒
```

### 从内存还原文字
> https://technet.microsoft.com/en-us/sysinternals/dd996900.aspx  
https://technet.microsoft.com/en-us/sysinternals/bb897439.aspx


```bash
procdump -ma notepad.exe notepad.dmp
strings notepad.dmp > notepad.txt
注:其他文字处理程序也适用
```
