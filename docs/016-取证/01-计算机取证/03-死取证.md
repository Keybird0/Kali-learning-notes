# 死取证
> 镜像硬盘或分区, 可以分析里面的所有文件, 包括删除的但存储位置未被覆盖的文件.

## 0x01 硬盘镜像
> 使用 kali 光盘启动计算机创建硬盘镜像文件, 应留足存储镜像文件的存储空间

### 工具
-	Dc3dd 来自美国空军计算机犯罪中心
-	Dcfldd
-	Guymager (图形化工具)

####  学习样例
> http://www.cfreds.nist.gov/Controlv1_0/control.dd

## 0x02 分析工具
- Autopsy
> bs架构, 使用简单

- DFF（Digital Forensics Framework）
> Kali2以上已删除源

- Extundelete
> 适用于ext3、ext4文件系统的反删除工具

```bash
extundelete [device-file] --restore-file [restore location]
```

- Foremost （美国政府开发) 
> 可以数据恢复,从内存dump中恢复文档图片,支持raw、dd、iso、vmem等格式

```bash
foremost -t jpeg,gif,png,doc -i xp.raw

foremost xx.cap
```

- binwalk
> 可以分析文件,和提权文件

```bash
binwalk xx.raw -e
```
