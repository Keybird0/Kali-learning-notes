# WeBug

> 国产 Web 漏洞靶场，中文友好

## 简介

WeBug 是一个集成了多种常见 Web 漏洞的练习平台，适合中文用户入门。

- 项目地址：[https://github.com/weburg/WeBug](https://github.com/weburg/WeBug)

## 包含的漏洞

- 逻辑漏洞
- 反射型 XSS
- 存储型 XSS
- SQL 注入
- 文件上传
- 文件包含
- 命令执行
- 越权访问

## 搭建

```bash
# 下载源码后部署在 PHP + MySQL 环境中
git clone https://github.com/weburg/WeBug.git
# 导入数据库并配置连接信息
```
