# 社会工程学

> 利用人性弱点（信任、好奇、恐惧等）进行攻击，是渗透测试中非常重要的一环。Metasploit 配合 SET（Social-Engineer Toolkit）可实现多种社会工程学攻击。

## 0x01 SET 社会工程学工具包

```bash
setoolkit
```

### 主要攻击类型

1. **Spear-Phishing Attack**: 鱼叉式钓鱼攻击
2. **Website Attack Vectors**: 网站攻击向量
3. **Infectious Media Generator**: 感染性媒体生成
4. **Create a Payload and Listener**: 创建payload和监听
5. **Mass Mailer Attack**: 大规模邮件攻击

## 0x02 网站克隆攻击

利用 SET 克隆目标网站，诱骗用户输入凭证:

1. 选择 `Website Attack Vectors`
2. 选择 `Credential Harvester Attack Method`
3. 选择 `Site Cloner`
4. 输入目标网站 URL
5. SET 在本地启动克隆站点
6. 诱导目标访问克隆站点

## 0x03 钓鱼邮件

- 利用 SET 生成携带恶意附件的邮件
- 配合 Metasploit payload 实现远程控制
- 支持自定义邮件模板和发件人信息

## 0x04 HTA 攻击

```
setoolkit → Website Attack → HTA Attack Method
```

生成恶意 HTA 文件，诱导目标打开后执行 payload。

## 0x05 防御建议

- 安全意识培训
- 邮件过滤和沙箱检测
- 多因素认证
- 定期进行社工模拟演练
