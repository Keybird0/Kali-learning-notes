# Msf 信息收集

## 0x01  nmap扫描
> `db_nmap` 使用方式参见nmap

## 0x02 Auxiliary扫描模块
### arp扫描

```
use auxiliary/scanner/discovery/arp_sweep

set rhosts 192.168.0.1/24
run
```

### UDP扫描

```
use auxiliary/scanner/discovery/udp_sweep
use auxiliary/scanner/discovery/udp_probe
```

### 僵尸主机扫描

```
找合格僵尸机
use auxiliary/scanner/ip/ipidseq
set rhosts 192.168.0.1/24
run

db_nmap -PN -sl ip(僵尸机) ip(目标主机)
```

### 端口扫描

```
search portscan
use use auxiliary/scanner/portscan/syn

set rhosts 192.168.0.1/24
set threads 50
run
```

### 密码嗅探
> 类似于dsniff, 支持从pcap中提取密码, 目前只支持pop3, imap, ftp, http GET

```
use auxiliary/sniffer/psnuffle
```

### snmp 扫描

```
use auxiliary/scanner/snmp/snmp_login (linux)
use auxiliary/scanner/snmp/snmp_enum
use (linux) auxiliary/scanner/snmp/snmp_enumusers (windows)
use auxiliary/scanner/snmp/snmp_enumshare (windows)
```

### smb扫描

```
# SMB版本扫描
use auxiliary/scanner/smb/smb_version
# 扫描命名管道,判断SMB服务类型(账号、密码)
use auxiliary/scanner/smb/pipe_auditor
# 扫描通过SMB管道可以访间的RCERPC服务
use auxiliary/scanner/smb/pipe_dcerpc_auditor
# SMB共享枚举(账号、密码)
use auxiliary/scanner/smb/smb_enumshares
# SMB用户枚举(账号、密码)
use auxiliary/scanner/smb/smb_enumusers
# SID枚举(账号、密码)
use auxiliary/scanner/smb/smb_lookupsid
```

### ssh扫描

```
# 版本扫描
use auxiliary/scanner/ssh/ssh_version
# 密码爆破
use auxiliary/scanner/ssh/ssh_login
# 公钥登录, 如树莓派默认系统统一公钥时可以尝试, 或通过其它方式获取到了公钥
use auxiliary/scanner/ssh/ssh_login_pubkey
set KEY_FILE id_rsa
set USERNAME root
run
```

### ftp扫描

```
# 查找版本信息
use auxiliary/scanner/ftp/ftp_version
# 查找可匿名登录的ftp
use auxiliary/scanner/ftp/anonymous
# 登录爆破
use auxiliary/scanner/ftp/ftp_login
```

### mssql扫描

```
# 端口扫描,TCP 1433 (动态端口) / UDP 1434 (查询TCP端口号)
use auxiliary/scanner/mssql/mssql_ping
# 爆破mssql密码
use auxiliary/scanner/mssql/mssql_login
# 远程执行代码
use auxiliary/admin/mssql/mssql_exec
set CMD "net user user pass /ADD"
```

### 查找系统缺少补丁
> 只支持基于已经取得session进行检测, 若检查失败, 可以尝试迁移到另一个进程再尝试.

```
use post/windows/gather/enum_patches
```

### 其它

```
use auxiliary/scanner/[tab]
# 会提示显示所有扫描模块
```
