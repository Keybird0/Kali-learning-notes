# Whois 信息查询

## 0x01 相关概念
Whois即域名或IP注册信息.且不同地区有不同whois信息.可能可以查询到注册人姓名,邮箱,地址等等信息.

## 0x02 查询方式
### 在线查询
国外的网站查国内的域名一般不太好试,不作推荐.可以使用站长之家,反查功能挺好用的.
http://whois.chinaz.com/
