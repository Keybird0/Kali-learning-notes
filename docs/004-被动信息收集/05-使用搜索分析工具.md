## 0x01 信息搜索工具
### theharvester
电子邮件，用户名和主机名/子域名信息收集工具.它收集来自各种公开的信息来源.  
使用帮助:
```
Usage: theharvester options 

       -d: Domain to search or company name
       -b: data source: google, googleCSE, bing, bingapi, pgp, linkedin,
                        google-profiles, jigsaw, twitter, googleplus, all

       -s: Start in result number X (default: 0)
       -v: Verify host name via dns resolution and search for virtual hosts
       -f: Save the results into an HTML and XML file (both)
       -n: Perform a DNS reverse query on all ranges discovered
       -c: Perform a DNS brute force for the domain name
       -t: Perform a DNS TLD expansion discovery
       -e: Use this DNS server
       -l: Limit the number of results to work with(bing goes from 50 to 50 results,
            google 100 to 100, and pgp doesn't use this option)
       -h: use SHODAN database to query discovered hosts

Examples:
        theharvester -d microsoft.com -l 500 -b google -h myresults.html
        theharvester -d microsoft.com -b pgp
        theharvester -d microsoft -l 200 -b linkedin
        theharvester -d apple.com -b googleCSE -l 500 -s 300
```
使用实例:
```
theharvester -d sina.com -l 300 -b google -f sina.html
```

### metagoofil
利用搜索引擎,搜索特定类型文件
使用帮助:
```
 Usage: metagoofil options

         -d: domain to search
         -t: filetype to download (pdf,doc,xls,ppt,odp,ods,docx,xlsx,pptx)
         -l: limit of results to search (default 200)
         -h: work with documents in directory (use "yes" for local analysis)
         -n: limit of files to download
         -o: working directory (location to save downloaded files)
         -f: output file

 Examples:
  metagoofil.py -d apple.com -t doc,pdf -l 200 -n 50 -o applefiles -f results.html
  metagoofil.py -h yes -o applefiles -f results.html (local dir analysis)

```
使用实例:
```
metagoofil -d sina.com -t pdf -l 200 -o test -f 1.html
```

### recon-ng
**必学的全特性信息收集框架**
特点:
- 命令格式与msf一致
- 基于Python开发
- 使用方法:模块, 数据库, 报告

具体使用:
全局选项
进入recon-ng之后,`show option`
> - USER-AGENT 
> - Proxy 
> - Workspace 
> - Snapshot

显示数据库的数据表结构
> `show schema`

帮助信息  
显示当前目录帮助
> `help`
  
举例:

## 0x02 分析文件信息工具
主要是分析METADATA即文件元信息
### 分析图片EXIF信息
EXIF可以记录GPS,设备信息,光圈大小,曝光时间等等,当然也可以做数据隐藏.一般来说,安全工作者感兴趣的一般就是GPS信息.
EXIF分析工具:
- 自带exif:
`exif image.jpg`
- 可以`apt install exiftool`
然后`exiftool image.jpg`
- 一般还可以右键属性查看详细信息,信息基本一样的.
- 
### Win平台的FOCA和SearchDiggity
不仅仅可以分析图片的元信息,还可以分析其它文件的元信息.
下载地址:
可以从网络下载目标文件,还可以榨取这些文件的元信息.也可以用它榨取其它自己感兴趣的文件.
