## 0x02 信息利用
###  生成密码字典
使用CUPP(Common User Password Profiler),按个人信息生成专属密码字典
```
默认不自带,需要下载:
git clone https://github.com/Mebus/cupp.git
python cupp.py -i //交互式输入生成密码
```
