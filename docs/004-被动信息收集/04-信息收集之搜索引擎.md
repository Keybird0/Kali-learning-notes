## 0x02 搜索引擎
### SHODAN
网站:[http://www.shodan.io/ ](http://www.shodan.io/)  
搜索内容:搜索联网的设备 
Banner:`http、ftp、ssh、telnet`   
常见filter:
```
hostname：搜索指定的主机或域名，例如 hostname:"google"
port：搜索指定的端口或服务，例如 port:"21"
country：搜索指定的国家，例如 country:"CN"
city：搜索指定的城市，例如 city:"Hefei"
org：搜索指定的组织或公司，例如 org:"google"
isp：搜索指定的ISP供应商，例如 isp:"China Telecom"
product：搜索指定的操作系统/软件/平台，例如 product:"Apache httpd"
version：搜索指定的软件版本，例如 version:"1.6.2"
geo：搜索指定的地理位置，参数为经纬度，例如 geo:"31.8639, 117.2808"
before/after：搜索指定收录时间前后的数据，格式为dd-mm-yy，例如 before:"11-11-15"
net：搜索指定的IP地址或子网，例如 net:"210.45.240.0/24"
os: 搜索特定的系统,例如: os: "windows"
server: 搜索特定的服务, 例如: server: "ssh", server: "Apache2.2.3"
```

搜索技巧实例:
```
1. 200 OK cisco country:JP            
2. user:admin pass:password            
3. linux upup avtech  
```

常用的参数有：
```
OS：win32
OS：Win Database-MySQL
OS：CentOS
OS: Red Hat
Port:常用的端口有：HTTP (80)、FTP (21)、SSH (22)、SNMP (161)、SIP (5060)
```

此外,shadon还提供了浏览器插件扩展,方便直接调用,查看shodan的信息.Firefox, Chrome均有扩展插件.

### Google
Google Haking 语法
```
intext: 把网页中的正文内容中的某个字符做为搜索条件.
allintext:使用方法和intext类似. 
intitle: 搜索网页标题中是否有我们所要找的字符.
cache: 搜索google里关于某些内容的缓存,有时候往往能找到一些好东西. 
define: 搜索某个词的定义,例如搜索:define:傻逼,将返回关于“傻逼”的定义. 
filetype: 搜索制定类型的文件，例如：filetype:doc.将返回所有以doc结尾的文件URL.
info: 查找指定站点的一些基本信息. 
inurl: 搜索我们指定的字符是否存在于URL中.常用于查找通用漏洞、注入点、管理员登录的URL
allinurl:也同inurl类似,可指定多个字符. 
linkurl: 例如搜索:inurl:test.cn可以返回所有和test.cn做了链接的URL. 
site: 搜索指定域名,如site:test.cn.将返回所有和test.cn有关的URL. 
```

一些实例:
```
含充值不含支付------------------+充值-支付                                                          
北京的电子商务公司---------------北京intitle:电子商务 intext:法人 intext:电话
阿里网站上的背脊公司联系人--------北京 site:alibaba.com inurl:contact
塞班司法方案的PDF文档-----------SOX filetype:pdf                         
法国的支付相关页面--------------payment site:fr

搜思科交换机----------------------------inurl:"level/15/exec/-/show"
搜网络摄像头----------------------------intitle:"netbotz appliance" "ok"
搜后台---------------------------------inurl /admin/login.php
搜qq密码-------------------------------inurl:qq.txt
搜账号密码文件--------------------------filetype:xls "username | password“
搜ftp密码文件--------------------------inurl:ftp "password" filetype:xls site:baidu.com
搜FrontPage的漏洞,可以直接搜到账号密码----Service.pwd         
```
